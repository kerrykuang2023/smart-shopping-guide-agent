# Product Images

This directory holds all product images referenced from the knowledge base YAML files.

## Naming Convention

```
<sku-prefix>-<type>.<ext>
```

Examples:
- `chenguang-k35-hero.jpg`     (main hero image)
- `chenguang-k35-front.jpg`    (front view)
- `chenguang-k35-tip.jpg`      (detail: pen tip)
- `chenguang-k35-clip.jpg`     (detail: clip)
- `chenguang-k35-writing.jpg`  (in-use)
- `chenguang-brand.jpg`        (brand story)

## Image Specifications

| Type | Size | Format | Max File Size |
|------|------|--------|---------------|
| Hero (main) | 1200×900 or 1600×1200 | JPG/WebP | 300 KB |
| Gallery (multi-angle) | 800×800 | JPG/WebP | 200 KB |
| Selling point | 600×400 | JPG/WebP | 150 KB |
| Thumbnail (auto-generated) | 200×200 | WebP | 30 KB |

## Recommended Photo Setup (DIY)

For self-shooting all 5 pens:

1. **Background**: White A4 paper or light grey cardboard
2. **Lighting**: Window-side daylight + a desk lamp opposite to fill shadows
3. **Camera**: Smartphone (any modern phone) with HDR on
4. **Angles to capture (per pen)**:
   - 整体平铺 (Hero) — pen lying flat, full body visible
   - 正面立放 (Front) — pen standing, label facing camera
   - 笔尖微距 (Tip detail) — close-up of nib/tip, use macro mode
   - 笔夹特写 (Clip detail) — close-up of clip
   - 书写效果 (Writing) — pen + a sample line on a notebook
5. **Time estimate**: ~30 minutes for all 5 pens × 5 angles = 25 photos
6. **Post-processing**: Crop to square/landscape, lightly boost brightness, export at 1200px wide

## Optimization

Before committing, all images should be:
- Compressed via [TinyPNG](https://tinypng.com/) or [Squoosh](https://squoosh.app/)
- Stripped of EXIF metadata
- Ideally in WebP format (or JPG for compatibility)

## Backend Image Serving

The backend exposes images at `/images/<filename>` and supports dynamic resizing:

```
/images/chenguang-k35-hero.jpg              # Original
/images/chenguang-k35-hero.jpg?w=200        # Width 200, auto height
/images/chenguang-k35-hero.jpg?w=800&q=75   # Width 800, quality 75
```

WebP conversion happens automatically when client supports it (`Accept: image/webp`).

## Adding New Images

1. Place image in this directory following naming convention
2. Reference it in the corresponding product YAML at `knowledge/products/<sku>.yaml`
3. Restart backend (or it auto-reloads in dev mode)
